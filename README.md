# Оглавление

 Введение
 1. Принципы чистого кода
   1.1. KISS (Keep It Simple, Stupid — «Делай проще»)
   1.2. DRY (Don't Repeat Yourself — «Не повторяйся»)
   1.3. YAGNI (You Aren't Gonna Need It — «Вам это не понадобится»)
   1.4. Дополнительные принципы чистого кода
 2. Принципы объектно-ориентированного проектирования (SOLID)
   2.1. S — Single Responsibility Principle (Принцип единственной ответственности)
   2.2. O — Open/Closed Principle (Принцип открытости/закрытости)
   2.3. L — Liskov Substitution Principle (Принцип подстановки Барбары Лисков)
   2.4. I — Interface Segregation Principle (Принцип разделения интерфейса)
   2.5. D — Dependency Inversion Principle (Принцип инверсии зависимостей)
 3. Принципы проектирования архитектуры
   3.1. Слабая связанность (Low Coupling)
   3.2. Высокая связность (High Cohesion)
   3.3. Разделение ответственности (Separation of Concerns)
   3.4. Дополнительные архитектурные принципы
 4. Принципы процесса разработки
   4.1. Agile и итеративность
   4.2. CI/CD (Continuous Integration / Continuous Delivery)
   4.3. TDD (Test-Driven Development)
   4.4. Рефакторинг
   4.5. Code Review (Ревью кода)
   4.6. Документация
   4.7. Версионирование
 5. Командные и организационные принципы
 6. Современные тенденции
 7. Антипаттерны (чего избегать)
 Заключение
